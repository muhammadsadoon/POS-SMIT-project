Routes Documentation for the Project

This file lists all the API routes in the project, including their HTTP method, full path, purpose, and what they are designed for.

1. Route: POST /api/auth/register
   - Method: POST
   - Purpose: User registration
   - Description: Allows new users to register by providing user details. Calls registerVM to handle the registration logic and returns success or error response.

2. Route: POST /api/auth/login
   - Method: POST
   - Purpose: User authentication
   - Description: Allows existing users to log in by providing credentials. Calls loginVM to handle the login logic and returns success or error response (401 on failure).

3. Route: POST /api/projects/
   - Method: POST
   - Purpose: Create a new project
   - Description: Allows authenticated users to create a new project. Requires protection middleware. Calls createProjectVM with project name and user ID, returns the created project.

4. Route: POST /api/projects/:projectId/member
   - Method: POST
   - Purpose: Add a member to an existing project
   - Description: Allows authenticated users to add a member to a specific project by project ID. Calls addMemberVM with project ID and user ID to add, returns the updated project.

5. Route: POST /api/products/:projectId
   - Method: POST
   - Purpose: Create a product for a project
   - Description: Allows authenticated users to create a product associated with a specific project. Requires protection middleware. Calls createProductVM with project ID and product details, returns the created product.

6. Route: POST /api/orders/
   - Method: POST
   - Purpose: Create a new order
   - Description: Allows authenticated users to create an order. Requires protection middleware. Calls createOrderVM with order details and user ID, returns the created order.

7. Route: POST /api/stock/
   - Method: POST
   - Purpose: Update stock levels
   - Description: Allows authenticated admin users to update stock. Requires protection and admin role middleware. Calls updateStockVM with stock details and user ID, returns the updated product/stock info.
