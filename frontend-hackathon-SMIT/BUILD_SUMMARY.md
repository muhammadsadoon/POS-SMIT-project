## 🚀 Quick Start (3 Steps)

```bash
# 1. Install
npm install

# 2. Configure
echo "NEXT_PUBLIC_API_URL=http://localhost:3001/api" > .env.local

# 3. Run
npm run dev
```

Then open: **http://localhost:3000**
